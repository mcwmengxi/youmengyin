# 前端角色与核心挑战

> 理解前端在 AI Agent 系统中的定位、职责变化和核心挑战。

---

## 传统前后端分工 vs Agent 时代

| 维度 | 传统 Web 应用 | Agent 应用 |
|------|--------------|------------|
| 后端职责 | CRUD + 业务逻辑 | LLM 调用 + 工具编排 + Agent 循环 |
| 前端职责 | 渲染数据 + 表单交互 | 流式渲染 + 多步骤状态展示 + 工具调用可视化 |
| 通信协议 | RESTful API（请求-响应） | SSE / WebSocket / Streaming HTTP（持续推送） |
| 用户体验 | 即时响应 | 渐进式生成 + 思考过程可见 |
| 状态复杂度 | 简单请求状态 | 多维度 Agent 执行状态 |

### 六大核心挑战

1. **流式数据处理**：与传统的请求-响应模式不同，Agent 的响应是持续推送的流式数据，需要前端具备流式解析和实时渲染能力。

2. **Agent 状态可视化**：Agent 的执行过程包含「思考 → 行动 → 观察」的循环，前端需要将这些内部状态以用户可理解的方式呈现。

3. **工具调用前端化**：Agent 的工具调用需要在前端展示参数、执行状态和返回结果，甚至需要前端定义和注册工具。

4. **对话管理**：多轮对话上下文的维护、消息的持久化与恢复、历史对话的管理。

5. **浏览器端 AI**：随着 WebLLM、Chrome Built-in AI 等技术的发展，AI 推理可以直接在浏览器中运行，前端需要掌握这些新能力。

6. **安全边界**：Agent 可能执行危险操作（如删除文件、发送邮件），前端需要提供确认机制，让用户掌握最终控制权。
