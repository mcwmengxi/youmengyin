# Quick Start

## 1. /init 生成项目说明书

>这个指令是用‌来生成你的项目说明书，让⁢claudecode认识‌你的整个项目

## 2. /compact 压缩会话上下文

>虚假的意义‌：这个指令可以帮你⁢凝练你和claud‌e的对话，去其糟粕​取其精华，让claude生成的结果更快更准
>真实的意义‌：这个指令可以帮你⁢省钱🤓

## 3. /clear 清空会话上下文

>claud‌e在经过多轮对话后⁢，可能会出现大脑容‌量不足直接宕机..​.,这时就`clear`一下...当然直接退出重进也不是不行（麻烦一点）  

## 4. /add-dir 添加关注目录

>claude每次改动肯定不会把整个仓库全都扫一遍
>那本次改动，你希望让claude看到关注哪些目录，就可以用`/add-dir`指令

## 5. /review 代码审查

>代码提交前必备指令，每次提交代码前都要用这个指令检查一下代码是否符合要求
