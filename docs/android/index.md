# Android 学习路线 ⭐

## 学习路线总览

```
Kotlin 语法 → Android 基础组件 → UI 开发 → 数据存储 → 网络编程 → 架构设计 → 进阶主题
```

## 阶段一：Kotlin 语言基础

Kotlin 是 Android 开发的官方语言，掌握 Kotlin 是学习 Android 的第一步。

- [Kotlin 入门指南（JavaScript/TypeScript 开发者版）](kotlin/kotlin.md) - 专为有前端经验的开发者准备
- [Kotlin 学习路线图](kotlin/kotlin-roadmap.md) - 系统化的 Kotlin 学习路径
- [Kotlin 简介与环境搭建](kotlin/kotlin-introduction.md)
- [基本语法与数据类型](kotlin/kotlin-basics.md)
- [控制流程与范围函数](kotlin/kotlin-control-flow.md)
- [函数与高阶函数](kotlin/kotlin-functions.md)
- [面向对象编程](kotlin/kotlin-oop.md)
- [空安全机制](kotlin/kotlin-null-safety.md)

## 阶段二：Android 基础组件

理解 Android 四大组件和核心概念，是开发 Android 应用的基础。

- [Android 基础组件](basic.md) - Activity、Service、BroadcastReceiver、ContentProvider、Fragment、Intent

## 阶段三：UI 开发

学习 Android 界面开发，从传统 View 体系到现代 Jetpack Compose。

- [UI 开发](ui.md) - 布局系统、RecyclerView、自定义 View、Material Design、Jetpack Compose

## 阶段四：数据存储

掌握 Android 中的各种数据持久化方案。

- [数据存储](data-storage.md) - SharedPreferences、文件存储、SQLite、Room、DataStore

## 阶段五：网络编程

学习 Android 网络请求和数据解析。

- [网络编程](network.md) - HTTP 基础、OkHttp、Retrofit、WebSocket、JSON 解析

## 阶段六：架构设计

理解 Android 应用的架构模式，写出可维护的代码。

- [架构设计](architecture.md) - MVC/MVP/MVVM、Jetpack、依赖注入、Clean Architecture

## 阶段七：进阶主题

深入 Android 高级开发领域。

- [进阶主题](advanced.md) - 协程、性能优化、内存管理、构建与打包、测试

## 学习建议

| 阶段 | 内容             | 建议时间 | 难度       |
| ---- | ---------------- | -------- | ---------- |
| 一   | Kotlin 语言基础  | 2-3 周   | ⭐⭐       |
| 二   | Android 基础组件 | 2-3 周   | ⭐⭐⭐     |
| 三   | UI 开发          | 3-4 周   | ⭐⭐⭐     |
| 四   | 数据存储         | 1-2 周   | ⭐⭐       |
| 五   | 网络编程         | 1-2 周   | ⭐⭐       |
| 六   | 架构设计         | 3-4 周   | ⭐⭐⭐⭐   |
| 七   | 进阶主题         | 持续学习 | ⭐⭐⭐⭐⭐ |
