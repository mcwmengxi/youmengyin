# vscode

## 🐢vscode常用快捷键

行注释 ctrl + /
块注释 shift + alt + a (按习惯可修改为 ctrl + shift + /)
删除行 直接 ctrl + x 和剪切一样且不用选中整行(正常为 ctrl + shift + k)
向下向上复制行 shift + alt + up/down
多行批量缩进
  ctrl + ] 或 tab         //向右缩进
  ctrl + [ 或 shift + tab //向左缩进
向上/向下移动行(也可理解为交换该行与上/下一行) alt+ up/down
查找、替换 ctrl + f / ctrl + h
移动到行首/尾 home / end
