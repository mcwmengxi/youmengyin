# vscode

## 🐢vscode常用快捷键

> **摘要**：记录一下比较常用的快捷键使用

<!-- mac ===> window -->
Option ===> alt
Command ===> ctrl

基础编辑与格式化

| 功能                       | 快捷键                                     |
| -------------------------- | ------------------------------------------ |
| **格式化代码 (goimports)** | `⇧ + ⌥ + F` (Shift + Option + F)           |
| **命令面板**               | `⇧ + ⌘ + P` (Shift + Command + P)          |
| **打开/关闭终端**          | `⌃ + \`` (Control +`)                     |
| **整行上下移动**           | `⌥ + ↑ / ↓` (Option + Up/Down)             |
| **复制整行 (上/下)**       | `⇧ + ⌥ + ↑ / ↓` (Shift + Option + Up/Down) |
| **删除整行**               | `⇧ + ⌘ + K` (Shift + Command + K)          |
| **多光标编辑**             | `⌥ + Click` (Option + Click)               |
| **跳转到指定行**             | `Ctrl + g`                       |
| **多行末尾插入光标(先选中)**             | `Shift + Alt + I`                       |
| **选中代码**             | `Ctrl + L`                       |
| **批量缩进**             | ctrl + ] (tab)/ctrl + [ (shift + tab)                       |
| **折叠/展开）代码**             | `Ctrl + k + 0 / Ctrl + k + j`                       |

代码导航与智能感知

| 功能                    | 快捷键                            |
| ----------------------- | --------------------------------- |
| **跳转到定义**          | `F12` 或 `⌘ + Click`              |
| **查看定义 (悬浮预览)** | `Alt + F12` (Option + F12)          |
| **查找所有引用**        | `⇧ + F12` (Shift + F12)           |
| **重命名符号**          | `F2`                              |
| **显示问题面板**        | `⇧ + ⌘ + M` (Shift + Command + M) |
| **快速修复建议**        | `⌘ + .` (Command + . )            |
| **文件查找**            | `Ctrl + P`                     |
| **切换已打开的标签页** |  `Ctrl + Tab` |

其它

| 功能                    | 快捷键                            |
| ----------------------- | --------------------------------- |
| **打开设置页**          | `Ctrl + ,`                       |
| **打开快捷键页**          | `Ctrl + K + S`                       |
| **切换工作区**          | `Ctrl + r`                       |
| **自动换行**          | `Alt + z` // 一行文本超长，换行显示                       |
| **跳转到下一个错误或警告/前一个**          | `F8/shift + F8`                       |

Go 测试与调试

| 功能                     | 快捷键                  |
| ------------------------ | ----------------------- |
| **开始/继续调试**        | `F5`                    |
| **设置/取消断点**        | `F9`                    |
| **单步跳过 (Step Over)** | `F10`                   |
| **单步调试 (Step Into)** | `F11`                   |
| **单步跳出 (Step Out)**  | `⇧ + F11` (Shift + F11) |
| **停止调试**             | `⇧ + F5` (Shift + F5)   |
