## 学习建议

1. **按顺序学习**：建议从基础篇开始，逐章深入，不要跳跃。
2. **动手实践**：每学完一个章节，尝试自己写代码验证知识点。
3. **阅读官方文档**：本笔记只是辅助，[React 官方文档](https://react.dev/) 是权威参考。
4. **关注版本差异**：当前企业主流是 React 18，React 19 已正式发布，了解两者差异有助于面试和项目升级。
